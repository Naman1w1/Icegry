# ICEGRY — Premium Streetwear Storefront

A mobile-first, high-fidelity streetwear storefront clone featuring category pills, advanced filters, sort drawer, search overlay, cart side-drawer, product detail quick view, and responsive product grid.

## 🚀 Getting Started

### Prerequisites
- Python 3.x or Node.js

### Run Locally

Using NPM:
```bash
npm run dev
```

Or using Python directly:
```bash
python clone/serve.py
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

## 📁 Project Structure

- `clone/` — Storefront application
  - `index.html` — Main HTML entry point
  - `css/` — Stylesheets and micro-animations
  - `js/` — Application logic, product catalogue, and icon components
  - `assets/` — Brand assets & logos
  - `serve.py` — Local HTTP development server
- `package.json` — Project configuration and run scripts
